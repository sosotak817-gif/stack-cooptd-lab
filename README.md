# 스택 연구소 — 한국어 배치 DPS 시뮬레이터

원본: https://coop-tools.vercel.app/ / @.noodlesoup

## 실행

Node.js 24와 Python 3.11 이상. 외부 패키지 설치가 필요 없습니다.

```powershell
npm run build
npm test
npm start
```

http://localhost:4173 에 접속합니다. HTML 파일을 직접 열면 Worker가 작동하지 않습니다.

## 기능

- 원본 맵 이미지 5종. 내 진영/파트너 확대 및 전체 맵 전환.
- 초마신 19종을 클릭·드래그로 배치, 이동·교환·삭제·되돌리기.
- 진영별 초마신 레벨, 해방, 스킨, 전용 유물, 배치 웨이브, 보석 3슬롯/등급.
- 고유 스킬 조건, 에그비 부착, 계정 특성 5슬롯·유물·룬·도감·추가 능력치. 전체 원본 파라미터도 JSON으로 편집 가능.
- 동일 진영의 같은 초마신은 성장 세팅을 공유. 개체별 해방 여부 및 에그비는 별도.
- 원본 보스 배치 엔진으로 사거리·지원 시너지와 전투 시간/기믹을 반영. 실전 평균 DPS와 이론 DPS를 구분.
- 원본 해방 25프레임 스프라이트: 1–10 노랑, 11–19 파랑, 20 무지개.
- 로컬 저장, JSON 입출력, 배치 PNG 내보내기.

## 신규 전투력 정의

인게임에 전투력 수치가 없으므로 `LAB SCORE v0.2 = 실전 평균 DPS / 1,000,000,000,000`으로 새로 정의했습니다. 같은 맵, 대상, 계정 조건에서 비교하는 커뮤니티 지표입니다. 보편적인 계정 전투력이나 게임의 공식 수치가 아닙니다.

## 수집 범위와 소스

- `original/`: 공개 HTML, CSS, 배포 JavaScript와 해당 코드에서 참조되는 이미지의 원본 스냅샷.
- `collection.json`: 파일별 수집 결과. 일부 과거 표기 이미지 경로는 원본 서버에서도 404이며, 현재 이미지 이름과 대체 이미지로 처리합니다.
- `data.json`: 유닛 54종(원시 UNITS 56개), 보석 45종, 적/보스, 웨이브, 유물/룬/성장·해방 데이터와 원본 기본 파라미터.
- `inspect.cjs`: 번들 모듈을 등록하고 원본 export를 해석하는 로더.
- `build.cjs`: 실제 사용한 원본 모듈로 계산 엔진과 정적 사이트 생성.
- `ui/`: 한국어 배치 UI와 계산 Worker. 계산식은 원본 엔진을 사용.
- `ko.json`: UI 번역과 비공식 한국어 유닛 표기.

이는 공개 클라이언트 파일 확보이며 비공개 저장소의 TypeScript/React 소스, 서버 코드 또는 비공개 데이터 확보를 뜻하지 않습니다. 원본의 추정/누락 효과도 유지됩니다. 보존한 8개 원본 도구는 주요 용어 번역을 적용했으며 긴 설명 일부는 영어입니다. 원본의 재배포 라이선스는 확인되지 않았습니다. 원본/게임 이미지의 권리는 각 권리자에게 있습니다. 사용자 요청에 따라 로그인 없이 접속할 수 있는 공개 사이트로 배포합니다.

테스트: 유닛 108조건 및 배치 15조건에서 생성 엔진과 보존 원본 엔진의 결과 일치, 3개 등급 순위와 해방 단계 경계 확인. 브라우저 상호작용은 별도로 확인합니다.

수집 갱신은 `npm run collect` 후 `npm run build`입니다. 원본이 갱신되면 번들 모듈 ID도 바뀔 수 있으므로 `npm test`와 로더를 확인해야 합니다.

## 기본값·프리셋과 캐시

- 우상단 숫자는 기본 레벨 + 스킨 추가 레벨 / 해방 단계입니다. 에그비 등 전투 중 추가 효과는 계산에 별도로 적용합니다.
- 최대 DPS 자동 배치는 게임에서 사용할 수 없는 결과가 확인되어 UI를 숨기고 실행을 중지했습니다. 아래 탐색 설명은 비활성화된 구현의 기록입니다.
- 최대 DPS 탐색은 기존 편성의 캐릭터 수·진영·개체별 세팅을 유지하며 이동/교환 및 재시작 탐색을 수행합니다. 빈 맵에서는 선택 진영에 19종을 한 개체씩 편성합니다. 빠른 탐색 160평가/12초, 정밀 탐색 600평가/40초를 기본 예산으로 사용합니다. 한 번의 엔진 계산이 오래 걸리면 표시 시간보다 길어질 수 있습니다.
- 실전 평균 DPS를 목표로 하며 원래 배치보다 낮은 결과를 적용하지 않습니다. 탐색된 후보 중 최고 결과이며 전역 최적해 보장은 아닙니다.
- 헬리콥터 치명타 장판과 부두술사 폭풍 위치도 유닛 위치와 함께 탐색합니다. 지정된 진영별 치명타 장판 수와 폭풍 총중첩은 유지하며, 폭풍은 개별 중첩으로 분할·합칠 수 있습니다. 직접 연결한 부두술사가 이동하거나 교환되면 폭풍의 시전자 연결도 함께 이동합니다. 장판이 없으면 장판 편집 도구로 먼저 지정합니다.
- 별도 특성 세팅에서 진영별 최대 5개 특성을 추가·삭제하고 종류·등급·수치를 편집합니다. 원본 13종 및 등급별 범위를 사용하며 같은 특성의 중복 장착을 허용합니다. 전투 특성 4종은 원본 계산 엔진에서 반영하고 보상·편의 특성은 저장합니다.
- 실행 전 유닛·장판·양쪽 특성을 포함한 전체 배치/세팅은 브라우저 localStorage에 별도로 보관되어 새로고침 후에도 복원할 수 있습니다. 일반 되돌리기 기록도 최대 30단계 보관합니다.
- 모든 배치·세팅 변경을 자동 저장합니다. 계산 결과는 원본 엔진/계산 코드 버전, 맵, 대상, 양쪽 계정 파라미터, 보석/스킨, 개체별 위치·옵션을 포함한 SHA-256 키로 IndexedDB에 최대 1,500건 보관합니다. 조건이 달라지면 기존 결과를 재사용하지 않습니다.
- Service Worker는 앱과 사용한 이미지 자산을 로컬 캐시합니다. 페이지는 네트워크 우선, 자산은 버전별 캐시 우선이며 새 버전 활성화 시 이전 앱 캐시를 정리합니다. 브라우저 사이트 데이터 삭제 시 저장 배치와 캐시가 삭제됩니다.

- 미설정 초마신의 기본값은 1레벨, 0해방, 스킨 추가 레벨 0, 보석 미장착입니다. 이전 캐시의 원본 기본 세팅과 동일한 항목은 새 기본값으로 전환하고 직접 수정한 항목은 유지합니다.
- 클라라덱(11개체), 코블린덱(15개체)은 제공 이미지의 캐릭터·장판 위치 프리셋입니다. 선택한 진영만 교체하고 성장·보석·특성을 유지합니다. 적용 전 전체 상태는 되돌리기로 복원합니다.

## 파트너·도감·보유 보석

- 초기 모드는 내 진영만 표시·계산합니다. 파트너 추가 시 파트너 설정을 열고 함께 계산하며, 제외 시 저장된 파트너 데이터는 유지하고 계산·표시에서 제외합니다.
- 원본 도감: SS 0–9단계, 단계당 공격력 +30%; SSS 0–9단계, 단계당 공통 방어력 감소 +10%.
- 공통 방어력 감소는 원본 spawnShredOf의 활성 진영 합계(특성·SSS 도감·제단 등)를 사용합니다. 연구소 추가 표시 보정 = max(0, 1 - max(0, 75 - 방감)/100). 방감 70%이면 최종 표시 DPS에 0.95를 곱합니다. 원본 엔진의 방어력 계산은 유지하며, 예상 처치 시간은 원본 엔진 기준입니다.
- 진영별 보유 보석은 종류·등급·개수로 관리합니다. 수동 장착 시 목록에 자동 등록하며 같은 초마신 여러 개체는 공유 세팅의 장착 개수를 모두 사용합니다.
- 보석 추천은 배치를 고정하고 원본 엔진의 실전 DPS와 위 추가 보정으로 평가합니다. 보유 수량, 해방 3/10/20 슬롯, 일반/특수 슬롯, 중복 보석 제한을 지킵니다. 300평가/20초 내 좌표 탐색·교환으로 최고 후보를 제안하며 전역 최적해를 보장하지 않습니다. 적용 전 조합·예상 DPS를 표시하고 적용 후 되돌리기를 지원합니다.
- 신규 계산 검증은 verify-gem-tools.cjs에 포함됩니다.

## 설정 팝업·반응형·이미지 리포트

- 특성, 보석/도감/보유 목록, 초마신 설정은 native dialog 팝업으로 편집합니다. 모바일은 하단 시트와 고정 헤더, 내부 스크롤, 44px 터치 입력을 사용합니다. 메인 설정 버튼은 스크롤 중에도 접근할 수 있습니다.
- 캐릭터 목록에도 현재 진영의 기본+스킨 레벨/해방과 장착 보석을 표시합니다.
- 전투력 v0.2는 방감 보정 후 실전 DPS 1조당 1입니다.
- 이미지 저장은 클릭 시점의 상태를 복제하고 별도 Worker로 최신 DPS를 계산한 뒤 배치+전투력+DPS를 한 장의 PNG로 저장합니다. 내 덱만 사용하면 7x5, 파트너가 활성화되면 양쪽 7x11 배치를 포함합니다.

## 시간별 누적 기대 딜량

- 10/30/60초는 평균 DPS의 배수가 아니라 원본 전투 타임라인의 각 segment.rate를 구간 길이만큼 적분한 누적 피해입니다. 아이비의 Quiver of Will, 클라라의 Weapon Mod and the aim 등 원본 타수/공격 누적 성장과 사거리·기믹을 그대로 반영합니다.
- 전투 시작이 0초이며 보호막 피해를 포함하고 회복량을 차감하지 않습니다. 처치/이탈/원본 제한시간에서 중단하고 이후 공격을 가정하지 않습니다. 분리된 두 진영 타임라인은 각 spawn 시각을 반영해 합산합니다. 최종 누적 피해에도 동일한 연구소 방감 보정을 적용합니다.
- 원본의 기대값·구간 평균 모델을 사용하며 개별 프레임 확률 추첨을 새로 시뮬레이션하지 않습니다. 화면과 PNG에 동일한 계산값을 표시합니다.

## 거인 페이즈 예측

- 현재 맵의 GiantsBoss 대상에 같은 배치/장판/활성 진영 설정으로 원본 computeBossBoard를 별도 Worker에서 실행합니다. 일반 보스 선택과 기존 DPS 결과는 유지합니다.
- 전체 phaseLayers를 연속 계산한 kill.phases의 유한한 완료 시간만 클리어로 판정합니다. 페이즈별 누적 완료 시각, 미처치 페이즈의 보호막+체력 순피해 진행률, 이후 미도달을 표시합니다. 맵별 원본 제한시간을 따릅니다.
- 원본 처치 판정 기준이며 연구소의 75% 방감 부족 추가 표시 보정은 이 판정에 적용하지 않습니다. 돌/소환/압박 등 원본 기믹 기대값을 사용합니다. 설정 변경 시 결과와 실행 중 계산을 무효화하고, 중지 및 180초 시간 제한을 제공합니다. 동일 설정은 기존 IndexedDB 계산 캐시를 재사용합니다.

- 메인 초마신 설정은 보관함 팝업을 먼저 엽니다. 진영·검색·레벨/해방/보석 카드에서 초마신을 골라 편집하고 보관함으로 돌아갈 수 있습니다. 배치판의 개체 및 선택 개체 설정 버튼은 해당 개체 세팅으로 바로 열립니다.

- 거인 계산 시 활성 파트너 진영에 배치가 없다면 매번 계산 인원 팝업에서 선택합니다. 혼자 기준은 파트너 효과를 제외하며, 내 세팅 2인 기준은 내 계정/초마신 설정을 깊은 복사하고 배치/장판/폭풍 소유자를 반대 진영으로 반영합니다. 실제 저장 배치와 파트너 데이터는 수정하지 않습니다. 활성 파트너 배치가 있으면 원래 두 진영으로 바로 계산합니다. 결과에 계산 기준을 표시합니다.

- 거인 페이즈 카드에는 보호막+체력 총량, 원본 시간별 구간을 합산한 가한 피해, 회복 상쇄(있을 때), 부족 피해를 표시합니다. 유효 피해는 가한 피해-회복 상쇄를 0~해당 페이즈 총량으로 제한하며, 부족 피해는 총량-유효 피해입니다. 완료 페이즈는 부동소수점 잔차 없이 부족 0, 미도달 페이즈는 가한 피해 0/부족 전체 총량입니다. 표시 DPS의 연구소 추가 방감 보정은 원본 처치 판정과 동일하게 적용하지 않습니다.


## D1 솔로 전투력 랭킹

- 클라라덱/코블린덱의 고정 프리셋 배치와 장판을 사용합니다. 현재 내 계정의 성장·특성·보석을 적용하며 현재 배치판과 파트너는 변경하지 않습니다.
- 맵·보스(웨이브 포함)·덱·계산 버전별로 최고 1,000개 기록을 실제 보관하고 50개씩 조회합니다. 같은 브라우저는 각 분류에 최고 기록 하나만 남깁니다. 동점은 먼저 달성한 기록 우선이며 같은 밀리초면 내부 식별자로 순서를 고정합니다.
- 무료 플랜 CPU 예산을 고려해 계산은 브라우저 Worker에서 실행합니다. **미검증 커뮤니티 랭킹**이며 서버 재계산, 게임 계정 인증, 실제 보유 세팅 검증과 점수 위변조 방지는 제공하지 않습니다. 상품·보상 지급용 경쟁 순위로 사용하지 마세요.
- 닉네임은 중복 가능하며 게임 계정 식별자가 아닙니다. 갱신용 임의 비밀 토큰은 localStorage에, 서버에는 그 SHA-256 해시만 저장합니다. 브라우저 데이터 삭제/다른 기기 이용 시 기존 기록의 갱신 권한을 잃습니다.
- 등록 제한은 동일 접속 IP 기준 10초 간격·UTC 하루 100회입니다. 공유 IP 사용자에게도 합산 적용됩니다. IP 원문은 보관하지 않고 날짜와 결합한 해시만 저장합니다. 프록시/새 접속 등 모든 악용을 방지하는 장치는 아닙니다.
- 계산 엔진·Worker·프리셋 변경 시 별도 랭킹 버전이 생성됩니다. 이전 버전 기록은 조회에 섞지 않고 보관하므로 필요 시 관리자가 정리합니다.
- Python 정적 서버에서는 DB API가 없으므로 랭킹 연결 안내가 표시됩니다. 나머지 계산은 정상 작동합니다. API 응답은 Service Worker와 브라우저 캐시에 보관하지 않습니다.

### Cloudflare Pages 연결

GitHub 저장소 루트에 package.json과 functions/가 있습니다. Pages 빌드 명령은 `npm run build`, 출력은 `dist`, 배포 브랜치는 `main`으로 설정합니다. functions/ API가 있으므로 Git 연동 또는 Wrangler로 배포하세요.

1. Cloudflare 대시보드에서 D1 데이터베이스 `stack-cooptd-ranking`을 생성합니다.
2. D1 콘솔에서 `migrations/0001_rankings.sql` 전체를 실행합니다. 이미 생성된 테이블은 유지합니다.
3. Pages 프로젝트의 Settings → Bindings에서 D1 바인딩 이름을 **DB**로 지정하고 생성한 데이터베이스를 연결합니다. 운영 환경과 미리보기 환경은 별도 DB 사용을 권장합니다.
4. 바인딩 적용 후 재배포하고 사이트 하단의 솔로 랭킹을 펼쳐 등록/조회를 확인합니다.

CLI를 사용할 경우 `wrangler.example.toml`을 `wrangler.toml`로 복사하고 발급된 database_id를 입력합니다. 예시의 placeholder를 그대로 배포하지 마세요.

```powershell
npx wrangler login
npx wrangler d1 create stack-cooptd-ranking
# 위 결과로 wrangler.toml의 database_id를 채운 후:
npx wrangler d1 migrations apply stack-cooptd-ranking --remote
npm run build
npx wrangler pages deploy dist --project-name stack-cooptd-lab
```

로컬 DB 검증은 동일한 설정 파일을 준비한 다음 실행합니다. 로컬 DB는 운영 DB와 분리됩니다.

```powershell
npx wrangler d1 migrations apply stack-cooptd-ranking --local
npx wrangler pages dev dist
```

DB 연결/테이블 준비 전에는 API가 503과 안내 메시지를 반환합니다. `npm test`는 실제 SQLite에서 등록·갱신·분류·동점·상위 1,000개 정리·페이지 경계를 검증합니다.


### 랭킹 페이지와 결과창 순위

- 상단 메뉴의 솔로 랭킹은 `/rankings/` 전용 페이지로 이동합니다. 덱·맵·보스 선택은 URL에 반영해 같은 분류를 공유할 수 있습니다. 이 페이지에서도 저장된 내 세팅으로 프리셋 계산·등록이 가능합니다.
- 인게임 닉네임은 필수입니다(유니코드 1~20자, 제어 문자 제외). 순위표에는 인게임 닉네임을 표시합니다. 같은 브라우저에서 이름을 변경해 등록하면 점수가 낮아도 이름은 갱신하고 기존 최고 점수와 동점 우선순위는 유지합니다.
- 1~3위는 금·은·동, 4~10위는 순위별 색상의 왕관, 11~100위는 순위 숫자가 들어간 월계 배지입니다. 101~1,000위는 숫자만 표시합니다.
- 등록했지만 현재 보관된 상위 1,000개에 기록이 없으면 내 순위를 `1000+`로 표시합니다. 이 구분에 필요한 분류별 참여 여부는 브라우저에 보관합니다. 등록하지 않은 사용자는 `등록 전`으로 표시하며 정확한 1,001위 이하 순위는 계산하지 않습니다.
- 전투력 결과 카드에는 현재 보스와 일치하는 클라라/코블린 고정 솔로 프리셋의 **등록 최고 기록 순위**를 표시합니다. 100위 이내는 배지를 함께 표시합니다. 현재 편집 중인 점수의 예상 순위를 뜻하지 않습니다. 파트너나 사용자 배치에는 해당 순위를 붙이지 않습니다.
- 새 계산이 시작되면 이전 배지를 지우며, 늦게 도착한 이전 조회가 새 결과에 표시되지 않도록 처리합니다. 순위 조회는 최대 15초간 메모리에서 재사용하고 등록 직후에는 갱신합니다.
- 기존 D1 테이블 구조를 그대로 사용하므로 추가 마이그레이션은 필요하지 않습니다. 최초 DB 연결이 안 되어 있으면 위 Cloudflare 설정을 먼저 완료하세요.

## 심해 수압·진주 비교 / 최소 추가 강화 진주

- 원본 거인 타임라인 계산으로 적용 전후 페이즈별 피해/부족량을 비교합니다. 현재 진주를 유지하고 거인 강화 4종(종류별 공격력 5개, 고정 기본공격 3개, 치명피해 1개, 기본공격 1개)의 추가 구매를 탐색합니다. 활성 양쪽에는 동일 횟수를 추가하며 비용은 1인당 및 합계를 표시합니다.
- 목표는 전체 클리어 또는 현재 클리어+1 페이즈입니다. 수압 1~선택 상한, 추가 진주 0~선택 상한(최대12)에서 비용 오름차순으로 모든 선행 후보를 검사하고 첫 성공을 찾은 경우에만 범위 내 최소로 표시합니다. 수압을 낮추기 위한 감압 구매 비용·일시 페널티는 포함하지 않으며 수압은 독립적인 전투 조건입니다.
- 최대1,225평가/약4분 이후 새 후보를 시작하지 않으며 진행 중 원본 계산을 포함한 전체 7분 제한과 중지 기능을 제공합니다. 중단/미완료는 최소로 표시하지 않습니다. 완성된 원본 계산은 IndexedDB에 남아 재탐색에 재사용합니다. 적용 전에는 저장 세팅을 바꾸지 않고 적용은 되돌리기로 복원합니다.
- 모바일 이미지 저장은 PNG 생성 후 미리보기에서 사용자 탭으로 파일 저장/기기 공유를 수행합니다. 공유 미지원이면 길게 누르기와 새 창 열기를 제공하며 URL을 1초 후 제거하던 다운로드 방식을 개선했습니다. 데스크톱은 직접 다운로드를 유지합니다.

레벨·해방 검증: 원본의 지수형 레벨 공격력 성장, 캐릭터별 해방 공격력, 기본 레벨별 해방 상한을 그대로 사용합니다. 초마신 설정창에 레벨 성장 공격력·해방 보너스와 최신 전장 계산의 기본/최종 공격력을 표시합니다. `verify-levels.cjs`는 112개 원본 비교와 실제 전장 DPS, 스킨 레벨, 미해방 개체, 캐시 분리를 검증합니다.
